# Wiskie

Wiskie is a scheduling application designed to make planning more flexible by introducing customizable constraints and flexible time boundaries. The goal is to move beyond rigid scheduling by accommodating tasks and events that may not fit neatly into fixed time slots.

Features

Flexible Scheduling: Support for events with adjustable time boundaries and scheduling constraints.

Recurring Events: Plan recurring weekly events alongside one-time events.

Schedule Management: Create and manage scheduled events through a React-based interface.

Tech Stack

Frontend: React, TypeScript, Vite

Backend: Node.js

Development Status

Wiskie is currently under active development. The frontend and initial backend functionality are in place, with scheduling logic and constraint optimization planned for future development.
